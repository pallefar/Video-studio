## Configuration

**Environment:**
- `.env` file (git-ignored) - Per-machine configuration
- `.env.example` - Template with all Settings fields documented
- Configuration sourced via Pydantic Settings (prefix: uppercase, underscore-separated)
- Database URL: `DATABASE_URL=postgresql+psycopg://user:pass@host:port/dbname`
- Redis URL: `REDIS_URL=redis://host:port/db`
- S3/MinIO endpoint, credentials, bucket via `S3_*` variables
- API keys for external providers via `FAL_API_KEY`, `ELEVENLABS_API_KEY`, etc. (all optional)
- ComfyUI: `COMFY_URL` points to headless ComfyUI sidecar HTTP endpoint

**Build:**
- `pyproject.toml` - Python project metadata, dependencies, entry points
- `package.json` - JavaScript project metadata, npm scripts, dependencies
- `docker-compose.yml` - Local development infrastructure (Postgres, Redis, MinIO)
- Frontend production build: `web/dist/` generated by `npm run build` (mounted as static files under `/` in FastAPI)

## Platform Requirements

**Development:**
- Python 3.11+ (local venv)
- Node.js (for frontend builds)
- Docker & Docker Compose (for Postgres, Redis, MinIO services)
- GPU (NVIDIA CUDA 11.8+ for local Wan-lane generation; optional if using remote providers)
- ComfyUI headless instance (optional; required for local text-to-video/video-to-video generation)

**Production:**
- Python 3.11+ runtime
- PostgreSQL 16+ database
- Redis 7+ server
- MinIO or AWS S3 compatible object storage
- ComfyUI headless (if using local generation; otherwise API providers only)
- GPU (optional; remote GPU rental via Vast/RunPod/Lambda/TensorDock supported)
- Uvicorn ASGI server process (one per API, separate GPU/CPU worker processes)

## Database

**Primary:** PostgreSQL 16
- Tables managed via Alembic migrations
- ORM: SQLModel (Pydantic + SQLAlchemy)
- Schema defined in `packages/schema/models.py`
- Connection pooling: SQLAlchemy default

## Object Storage

**Service:** MinIO (local) or S3-compatible remote
- Interface: boto3 S3 client
- Endpoint: `S3_ENDPOINT` (e.g., `http://localhost:9000` or AWS S3 URL)
- Authentication: Access key + secret key (`S3_ACCESS_KEY`, `S3_SECRET_KEY`)
- Bucket: `S3_BUCKET` (default: `avatar-pipeline`)
- All objects private by design (no public ACL method exposed)

## Message Queue

**Service:** Redis 7
- Client: `redis-py` package
- Job queue: RQ (Redis Queue) framework
- Topology: Three separate queues (`gpu`, `cpu`, `wan`) for lane isolation
- GPU worker concurrency: 1 (exclusive lock, 24GB VRAM limit)
- CPU worker: Handles API calls, encoding, publishing
- Persistent: Redis data stored in Docker volume locally
