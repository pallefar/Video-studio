<objective>
The hardware half. Fill the one seam plans 02-01 and 02-02 deliberately left open — the
real MuseTalk face-detection and VAE-encode — and then produce the measurement the roadmap
names as this phase's acceptance.

Everything else in the path already exists and is already tested: the dispatch chain, the
GPU stage, the idempotency, the ObjectStore bridge, the invalidation, the reverse loader,
and the benchmark query. What is missing is a method on `MuseTalkEngine` that turns a loop
video into `coords.pkl` and `latents.pt`, and a `sync_chunk` that reads them back instead of
recomputing them.

This plan cannot start on a Mac. It needs the RTX 3090 host with `third_party/MuseTalk`
cloned, and it needs Phase 1's `MuseTalkEngine` to no longer be a `NotImplementedError`
stub. Its first task exists specifically to check that those preconditions really hold
before any code is written against them.

Purpose: runbook steps 4 and 5 (docs/workstation.md §5) — M2.3 and M2.4.
Output: a real latent cache, a measured speedup, and two ticked milestone boxes.
</objective>

| Boundary | Description |
|----------|-------------|
| `third_party/MuseTalk` -> worker import namespace | A vendored research repo joins the import namespace of the process holding the GPU |
