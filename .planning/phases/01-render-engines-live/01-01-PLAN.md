<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public package registries -> GPU host venv | PyPI packages and a GitHub clone execute setup code with the operator's privileges during install |
| upstream model weight hosts -> weights/ | MuseTalk's weight download pulls multi-GB binaries that are loaded into the worker process |
| third_party/MuseTalk -> python import path | A research repo joins the worker's module search path and can shadow project modules |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-SC | Tampering | pip/git installs in scripts/install_engines.sh | high | mitigate | Task 2 blocking-human legitimacy gate against official registry pages before first install; every [ASSUMED] package human-confirmed; MIT/Apache-2.0 licence check per CLAUDE.md |
| T-01-01 | Tampering | MuseTalk git clone | high | mitigate | Clone pinned to a 40-char commit SHA in Task 5; test asserts the SHA pattern so a drift back to a branch name fails CI |
| T-01-02 | Tampering | resemble-perth unpinned git ref (transitive) | medium | accept | Chatterbox's own dependency, not under this project's control; Task 3 records the resolved commit so a future change is detectable. Repinning would require forking Chatterbox — disproportionate for a single-user localhost tool |
| T-01-03 | Tampering | third_party/MuseTalk on the import path | medium | mitigate | Clone lives outside every declared package dir in pyproject.toml's `[tool.setuptools] packages`; plan 01-03 appends (never prepends) it to the module search path so project modules always win a name collision |
| T-01-04 | Denial of Service | MuseTalk weight download | low | accept | Multi-GB download can fill the disk; `weights/` is on the operator's own budgeted drive (CONCERNS.md "Model Zoo Disk Footprint") and the failure is loud and local |
| T-01-05 | Elevation of Privilege | installer running as the operator | low | accept | Single-user self-hosted tool on the operator's own workstation; no privilege boundary exists to cross |
</threat_model>
