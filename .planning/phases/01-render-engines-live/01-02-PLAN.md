<objective>
Close the two CPU-provable gaps in the render lane before real model code lands: models
are not actually warmed at boot, and nothing guards the engine interface contract.

RESEARCH.md Pitfall 2 documents the first as a real gap — M3 requires "models warm at
boot, never unloaded", but `worker_gpu/run.py:main()` never calls `get_engines()`; engines
load lazily inside the first job's `tts_stage`. RESEARCH.md's "Wave 0 Gaps" names the
second: a lightweight contract test asserting the real engines match the dev engines'
signatures, runnable without CUDA.

Both are authorable and fully verifiable on the Mac. Landing them in wave 1, parallel
with the workstation dependency bring-up (plan 01-01), means plan 01-03's tracer is
written against an already-guarded contract and an already-correct boot path.

Purpose: the code half of milestone M3.1 ("single long-lived process, models warm at
boot, never unloaded"). The GPU-host confirmation rides along with plan 01-03's smoke gate.
Output: a boot-warming worker entrypoint and the phase's CPU regression harness.
</objective>
